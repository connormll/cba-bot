# Corpus manifests

One JSONL file per scraper. Each line describes one document under
`contracts/` and is merged into the index metadata. The document itself may be
regenerated by `cba-bot scrape`; the manifest is the provenance record.

```json
{
  "file": "scraped/ny/oer/PEF_Professional Scientific_2023-2026.pdf",
  "title": "PEF Professional, Scientific and Technical Services (PS&T)",
  "url": "https://oer.ny.gov/system/files/documents/2024/05/2023-2026-cba-final-edition.pdf",
  "source": "ny",
  "union": "PEF",
  "employer": "State of New York",
  "sector": "public",
  "jurisdiction": "NY",
  "effective": "2023-01-01",
  "expiry": "2026-12-31",
  "notes": "NY OER state union contract"
}
```

Fields:

| Field | Meaning |
| --- | --- |
| `file` | Path relative to `contracts/` (required) |
| `title` | Display title |
| `url` | Original source URL |
| `source` | Scraper name (`cornell`, `opm`, `olms`, `ny`, `escholarship`, `states`, or an extra collector) |
| `union` | Union name, including local where known |
| `employer` | Employer or agency |
| `sector` | `public`, `federal`, `education`, `healthcare`, `private`, `nonprofit`, `other` |
| `jurisdiction` | Two-letter U.S. state, or empty for nationwide/federal |
| `effective` | Start date, `YYYY-MM-DD` |
| `expiry` | End date, `YYYY-MM-DD` |
| `notes` | Free-form provenance |

Missing dates are inferred from the filename. A document with only an expiry
date is treated as current until that date; a document in an `Expired/` folder
is marked expired even when its dates are incomplete.
